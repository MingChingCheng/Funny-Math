# Collatz Conjecture

Rule:

1. if n is even, then do n/2
2. if n is odd, then do n*3 + 1

Example:

- start with 5
- 5 -> 16 -> 8 -> 4 -> 2 -> 1 -> 4 -> 2 -> 1 -> ...
- looping

The conjecture is all positive integer will become to 1.
For now, every number people use computer to check fit this conjecture.
But we can not prove this conjecture is correct or not.
